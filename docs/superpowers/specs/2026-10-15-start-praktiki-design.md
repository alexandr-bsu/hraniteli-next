## 1. Контекст и Цели

Необходимо интегрировать функционал пилотного проекта **«Старт практики»** для трех психологов:
1. **Регистрация и карточка на Хранителях**:
   - Психологи самостоятельно регистрируются через специальный вебхук в Telegram-боте (`registration-psyco-start-practice`).
   - Заполняют стандартную анкету профиля (`https://hrani.live/psy-info`).
   - Проходят стандартную премодерацию администратором (`verified = true`, `allow_assignment = true`).
   - Карточка отображается **на главной странице (`/`)** вместе с психологами «Сообщества», но имеет отличительный маркер: специальную плашку **«Старт практики»** (без текста о стаже в сообществе).
   - Психологи участвуют в стандартных фильтрах (модальности, цена, пол), без создания отдельной вкладки фильтра.
   - Обычные посетители сайта могут бронировать их напрямую по указанной стоимости.
2. **Чат-бот откликов на заявки («Рука помощи» / пул заявок)**:
   - В чат-боте для психологов «Старт практики» лента заявок фильтруется строго: они видят **только бесплатные заявки** (`psychologist_price = 'Бесплатно'`), платные заявки исключаются из выдачи.
   - Лимит откликов: **1 бесплатный отклик в месяц** (счетчик `clients_rp = 1`).
   - Автоматическое пополнение: 1-го числа каждого месяца запускается Cron-воркфлоу в n8n, обновляющий `clients_rp = 1` для всех психологов с `group = 'Старт практики'`.
   - При успешном бронировании клиенту отправляется ссылка на профиль психолога на главной странице (`https://psy.hrani.live/?selected_psychologist=...`) и текст уведомления с указанием: *«...психолог из проекта «Старт практики» — [Имя]»*.

## 2. Архитектурные Решения и Компоненты

### 2.1. База данных Supabase (`hraniteli_psychologists`)
- Поле `group`: новое значение `'Старт практики'` (наряду с существующими `'Сообщество'`, `'Супервизии'`, `'Рука помощи'`).
- Поле `clients_rp`: используется для хранения остатка откликов на текущий месяц (по умолчанию 1).
- Поле `allow_assignment`: `false` при регистрации, переключается в `true` администратором после проверки анкеты.

### 2.2. Next.js Фронтенд (`src/`)
1. **`src/features/actions/getPsychologistAll.ts`**:
   - При запросе для главной страницы (`is_group === false`):
     ```typescript
     data = data.filter((psy: any) => psy.group === 'Сообщество' || psy.group === 'Старт практики')
     ```
   - При запросе для страницы групп (`is_group === true`):
     ```typescript
     data = data.filter((psy: any) => psy.group !== 'Сообщество' && psy.group !== 'Старт практики')
     ```
2. **`src/widgets/Card/Card.tsx`**:
   - Отрисовка плашки маркера:
     ```tsx
     {psychologist.group === 'Старт практики' ? (
       <div className={`${styles.experienceWrapper} px-2 py-1 rounded-full w-fit bg-[#f5f5f5]`}>
         <span className={styles.experience}>Старт практики</span>
         {psychologist.verified && (
           <Image src="/card/verified.svg" alt="Verified" width={23} height={23} style={{ marginLeft: '6px' }} unoptimized />
         )}
       </div>
     ) : (
       // Стандартный рендер опыта "X в сообществе"
     )}
     ```
3. **`src/widgets/HelpHandConfirmStages/ConfirmPsychologistForm.tsx`**:
   - `basePath`: если `group === 'Старт практики'`, ведет на главную (`/`), а не на `/groups`.
   - Отображение статуса/опыта в модальном окне подтверждения: отображать плашку «Старт практики».

### 2.3. n8n Воркфлоу
1. **`n8n/workflows/Регистрация психолога.json`**:
   - Добавить вебхук `registration-psyco-start-practice` (POST).
   - Ветвление: создание записи в `hraniteli_psychologists` с параметрами:
     - `group`: `"Старт практики"`
     - `clients_rp`: 1
     - `allow_assignment`: false
     - `subscribtion_payment_amount`: 0
     - `send_payment_link`: false
   - Генерация короткой ссылки на `https://hrani.live/psy-info?psychologist_id={{ $json.telegram_id }}`.
2. **`n8n/workflows/Получить все заявки из руки помощи.json`**:
   - Модификация SQL/Supabase фильтра заявок:
     - Если `group === 'Старт практики'` -> добавлять фильтр `&psychologist_price.eq.Бесплатно`.
   - Проверка лимита:
     - Если `clients_rp <= 0` -> блокировать отклик с сообщением о исчерпании лимита на текущий месяц.
3. **`n8n/workflows/Бронируем заявку руки помощи психологом.json`**:
   - Генерация ссылки на психолога для клиента:
     - Если `group === 'Старт практики'` -> `https://psy.hrani.live/?selected_psychologist=${name}`.
   - Текст сообщения клиенту:
     - Указать принадлежность к проекту «Старт практики».
4. **Ежемесячный Cron-воркфлоу (`Пополнение лимитов Старт практики.json`)**:
   - Триггер: `0 0 1 * *` (1-е число каждого месяца в 00:00).
   - Действие: Supabase node / PostgreSQL query:
     ```sql
     UPDATE hraniteli_psychologists
     SET clients_rp = 1
     WHERE group = 'Старт практики';
     ```
